# 玩家反馈信号表

> 直播间水友的抱怨不是噪音，是词库问题的诊断信号。
> 每次收到类似反馈，查这张表定位具体问题类型，然后去 SKILL.md 第4节找对应规则。

## 信号 → 问题类型映射

| 玩家原话 | 本质问题 | 对应规则 | 归因 |
|----------|---------|---------|------|
| 「全员天使环节」 | 词对太简单，一轮就能盘出双边 | 好题第一性原理 | 区分度过高，共性不够 |
| 「没有百科」 | 词太冷门，无人能描述 | 好题第四要素：可描述性 | 知识门槛太高 |
| 「词相似度太低……烂完」 | 两个词不在同一人设/设定范畴 | 好题三要素①同类型标签 | 为了出题硬凑 |
| 「你说完描述全场沉默」 | 冷门角色/设定 | 可描述性判断标准 | 默认毙掉 |
| 「这词我都没听过」 | 信息差失衡 / 冷门 | 可描述性 / 失败模式-信息差失衡 | 知名度不对等 |
| 「一眼看出他是那边的」 | 物理特征秒杀 / 身份特征秒杀 | 失败模式-致命级 | 外在特征暴露 |
| 「你的描述也能形容我啊」= 好的信号 | 信息差到位 | 反向检验法 | 题出对了 |
| 「说来说去都差不多分不清」= 好的信号 | 难度适中 | 难度校准⭐⭐ | 下一轮才该出结果 |
| 「白板提示词太广」 | 提示标签粒度过粗，白板无法缩小范围 | 白板出题规则①共同点 | 标签不够具体 |
| 「天使一看共同点就知道双边」 | 共同标签太简单（如「男主」），天使一轮锁死 | 好题第一性原理 | 共性标签粒度过粗，应细化到人设而非身份 |

## 处理流程

收到反馈 → 查表定位问题类型 → 确认词对是否还在词库中 → 若在，执行：

1. 移入「已移除」区，标注原因（引用玩家原话）
2. 检查 SKILL.md 对应规则是否需要补全
3. 若是新模式/新翻车 → 更新 SKILL.md 第4节失败模式

## 实例（2026-07-10 某场直播）

```
❝ 词特别简单导致快速进入全员天使环节
❝ 词相似度太低或没有百科导致烂完
```

→ 定位：好题第一性原理 + 可描述性
→ 补入了「一轮不能盘出双边」规则和「可描述性」第四要素
→ 新增了直播间术语对照表
